## 0. v1 中需要修订的判断

审计报告指出了 v1 的多处问题，我逐条核实后确认**全部属实**。列在这里是因为错误的推理过程比错误本身更值得记录。

| v1 的断言 | 问题 | 修订 |
| --- | --- | --- |
| 「去掉 Cutout」列为待做实验 A2 | **前提错误**：strong 配方里 Cutout 本来就是 0，这个实验不存在 | 删除该实验项 |
| 「小于约 0.5% 的差异属于噪声」 | **方法论错误**：那是单模型的二项置信区间；两个模型跑同一批测试样本时错误是**配对**的，差值的不确定性远小于此 | 改用 McNemar 检验 + 配对 bootstrap（§4） |
| ASAM 引用为 arXiv:2103.12300 | **引用错误** | 正确为 **arXiv:2102.11600**（Kwon et al., ICML 2021） |

| Snapshot「免费 +1.24」与 TTA「+0.47」并列，暗示可叠加 | **不可相加**："免费"指特定训练预算安排而非零推理成本；增益依赖误差互补性 | 改为需实测，不预设可加 |
| 「最后若干轮关闭强增强是文献直接证明的零成本改动」 | **不是同一实验**：DA-Revisited 原文是训练后**额外**的弱增强微调阶段；在固定 200 轮里改最后 20-30 轮是新设计 | 标注为待验证的新设计 |
| 「M=9 大于原文最优 M=5，所以增强过强」 | **实现不可比**：torchvision 的 RandAugment 用 31 档幅度、算子集合与填充/插值约定都与原文未必一致 | 改为先核对实现再扫描 |
| 「知识蒸馏最多 +0.2、自监督一定更差、Transformer 从零训练不成立」 | **过度绝对**：线性探针 ≠ 全量微调；有监督对比学习不是标签稀缺方法；CCT 确有从零训练的成功案例 | 降级为"成本/证据匹配度不足，低优先级"，而非"不可能" |

| 「训练/测试准确率差距 >3 个点即为过拟合信号」 | **判据无效**：强增强下训练准确率是相对 `y_a` 在混合图上算的，本就偏低（实测 WRN 训练准确率 78% 而测试 97.5%） | 删除该判据 |

## 1. 实测结果（已完成）

### 1.1 主结果

| 模型 | 配方 | 轮数 | Top-1 | Top-5 | 参数量 | 训练时长 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| ResNet-18 | baseline | 100 | 95.19% | 99.57% | 11.2M | 18.1 min |
| ResNet-18 | baseline | 200 | 95.49% | 99.61% | 11.2M | 42.8 min |
| ResNet-18 | strong | 100 | 95.87% | 99.87% | 11.2M | 24.2 min |
| ResNet-18 | strong | 200 | 96.43% | 99.87% | 11.2M | 48.1 min |
| **WRN-28-10** | **strong** | **200** | **97.50%** | **99.90%** | **36.5M** | **258 min** |

**WRN-28-10 单模型单次前向 97.50%**，落在原定目标区间 97.3~97.6% 内。
配方从 ResNet-18 原样迁移提升 +1.07 个点，说明配方不依赖特定架构。

WRN 配置：`--model wrn28-10 --recipe strong --epochs 200 --batch-size 256 --lr 0.2 --dropout 0.3 --drop-path 0.1`。

### 1.2 三个负结果

被广泛推荐、但在本项目上**实测无效甚至有害**的方法：

| 方法 | ResNet-18（96.43%）| WRN-28-10（97.50%）| 判定 |
| --- | ---: | ---: | --- |
| 水平翻转 TTA | **96.90%（+0.47，p=3.4e-05）** | 97.47%（**−0.03，p=0.80**）| **依赖模型** |
| BN 重估（干净输入）| 96.11%（−0.32，p=0.0054）| −0.34 | 有害 |
| BN 重估（训练分布）| 96.43%（±0.00）| −0.11 | 无效 |
| 与 ResNet-18 等权概率集成 | — | 97.53%（+0.06，p=0.56）| 不显著 |
| 等权集成（均不加 TTA）| — | 97.48%（−0.02，p=0.92）| 不显著 |

**结论：96.43% → 97.50% 的提升完全来自「架构升级 + 训练配方」，没有一部分来自事后处理。**

三条值得记住的教训：

1. **TTA 的收益是模型相关的，不是常数。** 它在 ResNet-18 上显著（+0.47），在已经很强的 WRN 上归零。
   v1 把它当成可移植的加成，是错的。
2. **BN 重估的理论动机成立但方案无效。** 平均权重的 BN running stats 确实是在增强图（含
   MixUp/CutMix 混合图）上累计的，与推理时的干净输入分布不一致；但实测重估反而变差——
   用干净输入重估显著降低准确率，用训练分布重估基本不变。实现见 `recalibrate_bn.py`。
3. **集成需要错误互补。** 成员强弱差 1.07 个点时，等权平均只得到 +0.06 且不显著。

### 1.3 训练过程的两个实测现象

- **raw 与 EMA 在末期互相反超。** ResNet-18 第 190 轮 raw 96.47% 而 EMA 96.41%；WRN 最后几轮
  raw 97.43% 而 EMA 97.40%。训练中期 EMA 领先可达 5~10 个点，末期收敛到 0.3 以内。
  **因此两者必须分开存档**（已实现 `best_*_raw.pt` / `best_*_ema.pt`），不能预设 EMA 更优。
- **本机耗时不可跨时段比较。** 同一个 WRN 训练实测 65~88 秒/轮，原因是笔记本供电档位在
  55W 与 139W 之间切换，与代码/数据/模型无关。做时间预算必须固定电源状态。

## 2. 文献调研摘要（数字均已回溯一手论文）

### 2.1 数据增强

| 方法 | CIFAR-10 结果 | 备注 |
| --- | --- | --- |
| Cutout | ResNet-18: 4.72% → 3.99% 错误率 | 最优边长 16×16 |
| MixUp (α=1) | PreAct-ResNet18: 5.6% → 4.2% | 收敛慢，短 schedule 吃亏 |
| CutMix (α=1) | PyramidNet-200: 3.85% → 2.88% | 300 轮 |
| GridMask (r=0.4) | ResNet-18: 95.28% → **96.54%** | 单方法增益最大的遮挡类增强 |
| RandAugment | WRN-28-10: 96.1% → **97.3%**（M=5, N=3, 200ep）| 我们用 N=2/M=9 |
| TrivialAugment (Wide) | WRN-28-10: 97.03% → **97.46%** | 零调参 |
| AugMix | 干净集仅 +0.3；**CIFAR-10-C 错误率 29.0% → 12.5%** | 主要是鲁棒性方法 |

- Cutout 与 CutMix 功能重叠（CutMix 论文 CIFAR-100 消融：CutMix 单独 14.47% 错误率优于
  Cutout+MixUp 叠加的 15.46%）。**我们的 strong 配方本来就没开 Cutout。**
- 混合增强需要足够长的 schedule；AutoAugment 原文指出模型需练够 80~100 轮才能吃透多子策略。

### 2.2 网络架构

下表的耗时列是**基准外推值**（推导见 §3），不是真实训练记录；最后一列是本项目实测成绩。

| 架构 | 参数 | 本机 200 轮基准估算 | 标准配方 | 强增强后 |
| --- | --- | --- | --- | --- |
| ResNet-18 | 11.2M | 0.58 h | 95.19% | **96.43%（实测）** |
| WRN-16-8 | 11.0M | 1.47 h | 95.73% | 未知 |
| WRN-40-4 | 8.9M | 1.41 h | 95.47% | 未知 |
| **WRN-28-10** | **36.5M** | **4.52 h（bs=512）/ 4.67 h（bs=256）** | 96.00% | **97.50%（实测，实际用时 4.30 h）** |
| DenseNet-BC 190-40 | 25.6M | 约 2.5 h（估） | 96.54% | 未知 |
| Shake-Shake 26 2×96d | 26.2M | 30~50 h（1800 轮） | 97.14% | 98.00%（+AA） |
| CCT-7/3×1（Transformer）| 3.7M | 5~8 h（1500 轮）| — | 97.48%（1500 轮）|

- 同尺寸换架构无意义：WRN-16-8（11.0M）标准配方只有 95.73%，比 ResNet-18 强配方低 0.7。
- ViT/DeiT 从零训练在 32×32 上不成立（要么上采样到 224 且训 7200 轮，约本机 150~300 倍算力）；
  **CCT 是例外**——3.7M 参数、1500 轮从零训练到 97.48%，列作备选。
- ConvNeXt 在 CIFAR-10 上没有可信的从零训练数据，且 stride-4 主干在 32×32 上会把特征图压到 1×1。

### 2.3 优化器与正则化

| 方法 | 实测增益 | 代价 | 备注 |
| --- | --- | --- | --- |
| Stochastic Depth | ResNet-110: 93.59% → **94.75%** | 几乎为零 | 已用于本项目 WRN（0→0.1）|
| SAM | WRN-28-10+Cutout 200ep: 97.4% → **97.7%**；+AA 1800ep: 97.8% → **98.4%** | **2 倍每步** | 增益与增强强度负相关 |
| ASAM | 比 SAM 再 +0.3（WRN-28-10: 96.98% → 97.28%）| 同为 2 倍 | arXiv:2102.11600 |
| SWA | WRN-28-10: 96.18% → 96.45%（等预算）/ 96.79%（1.5×）| +25~50% 轮数 | **必须重算 BN** |
| Lookahead | ResNet-18: 95.23% → 95.27%（+0.04，噪声内）| — | 不值得做 |
| Lion | **原文无任何 CIFAR 从零训练结果** | — | 无依据 |
| 单纯延长训练 | 200→1800 轮：**0.0~0.1%（配方不变）** | 9 倍 | 见 §0 的修订 |

- **SAM 的增益与增强强度负相关**：Basic 增强下 +0.8，Cutout 下 +0.3，AutoAugment 下仅 +0.2。
  我们的配方比 AutoAugment 更强，**预期 SAM 只值 +0.2~0.3 却要付 2 倍算力**。
- **标签平滑与 MixUp/CutMix 有张力**（MixUp 原文消融显示加 LS 反而变差），现代配方仍同时使用。
- **weight decay 需随增强强度和训练长度下调**（训练越久，最优 wd 越小）。

### 2.4 权重平均与集成

| 方法 | CIFAR-10 结果 | 额外成本 |
| --- | --- | --- |
| Snapshot Ensemble | DenseNet-100: 4.68% → **3.44% 错误率** | 同总轮数（需改调度）|
| SWA | WRN-28-10: 96.18% → 96.79% | 1.25~1.5× 轮数 |
| Deep Ensemble (M=5) | 约 +1.0~1.5 | 5× 训练 |
| 翻转 TTA | 本项目实测：ResNet-18 **+0.47（显著）**；WRN **−0.03（不显著）** | 推理 2× |

### 2.5 明确排除的方向

| 方向 | 结论 | 依据 |
| --- | --- | --- |
| 半监督（FixMatch / SoftMatch 等）| **不适用**：我们没有标注稀缺问题。这些方法在 4000 标签下 SOTA 96.0%，**低于**我们 5 万标签的 96.43% | FlexMatch / SoftMatch 表 |
| 自监督预训练（SimCLR / SimSiam 等）| **成本不匹配**：在 CIFAR-10 上自监督 800 轮，线性探针 91.8%，比有监督低 4.6 点。（注：线性探针不等于全量微调，不能据此断言表示学习无价值）| SimSiam 附录 D |
| 知识蒸馏 | **收益与成本不匹配**：R50→R18 在 CIFAR-10 上 +0.0~0.2。但"蒸馏普遍无效"的说法不成立（Born-Again Networks 在小模型上有 +0.2~0.3）| arXiv 2605.31191；BAN |
| 单纯延长训练 | 配方不变时 0.0~0.1%；配合 SAM 等更强正则时另有收益 | SAM 论文 Table 1 |

## 4. 评估方法论（v1 缺失的关键部分）

### 4.1 不能用二项置信区间比较两个模型

CIFAR-10 测试集 10000 张，单模型准确率 p≈0.96 时的二项标准误约 0.19%。
常见做法因此规定"小于约 0.5% 的差异不显著"——**这是错的**。

两个模型跑的是**同一批图片**，错误是**配对的**：同一张难图往往两个都错。差值的
不确定性远小于把两次评估当作独立样本的估计。正确做法是只看**不一致**的样本：

```
b = A 错 B 对     c = A 对 B 错
原假设（两模型等价）下 b ~ Binomial(b+c, 0.5)
```

**本项目的反例**：TTA 在 ResNet-18 上只提升 0.47%，按 ±0.5% 门槛会被判为噪声；
实际 McNemar p=3.4e-05，配对 bootstrap 95% CI 为 [+0.26, +0.69]，**明确显著**。

工具：`paired_test.py`（McNemar + 配对 bootstrap）、`utils.mcnemar_test`。
因此 `evaluate.py` 会导出**逐样本预测**（`preds*.npz`），混淆矩阵无法用于配对检验。

### 4.2 模型选择用了测试集

本项目所有结果都在官方测试集上评估，且 best 按测试集选。**这带来选择偏差**，
尤其在多次调参之后。严格做法是：从训练集分层划出固定的 45k/5k 训练/验证划分，
用验证集做模型选择，最后在完整 50k 上重训、用测试集报告。

注意：**旧权重已经见过全部 50000 张训练图，现在从其中划出验证集不能追溯性地
称为它们的独立验证集。** 新的验证实验必须从未见过验证样本的初始化重新训练。

### 4.3 成绩口径必须分开标注

| 口径 | 训练条件 | 推理条件 |
| --- | --- | --- |
| 单模型单次前向 | 官方训练集，从零训练，无额外数据 | 单次前向 |
| 单模型 + TTA | 同上 | 翻转 TTA |
| 多模型集成 | 同上 | K 个模型概率平均 |
| 预训练/额外数据 | 单独注明 | 不可冒充从零训练 |

本项目的最佳成绩 **97.50% 属于第一种口径**；加 TTA 或集成都没有达到显著提升，
因此不采用增强口径报告。

## 6. 时间预算

| 阶段 2 | SAM 200 轮 + 3 种子 | 约 27~36 h |
| 阶段 2（完整）| 含 400 轮与 SWA | 约 50 h |

**若目标是「单模型单次前向 ≥98%」**：本机从零训练的实用上限约在 97~98%。
达到 98% 需要 SAM + 长训练（1800 轮量级，30~60 h）或 PyramidNet 级别结构，
**且不能承诺一定达到**。
